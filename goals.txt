Ascii maze game inspired by Gear_U on youtube.com

The game contains the following:
    - a dynamic maze map (randomized depth-first search algorithm)
    - title screen ✅
    - character selection ✅
    - a player placed on a random position ✅
    - an enemy placed on a random position ✅
    - exit placed on a random position ✅
    - a level counter
    - game over screen
